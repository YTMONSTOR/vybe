# VYBE — видеоплатформа нового поколения

Java 17 · Spring Boot 3.3 · Spring Security · Spring Data JPA · PostgreSQL · Thymeleaf · WebSocket · Lucide

## Быстрый старт

Требуется: **JDK 17+**, **Maven 3.9+**, **Docker** (или локальный PostgreSQL). Опционально — **ffmpeg** в `PATH` (серверная генерация обложек и точная длительность).

```bash
# 1. База данных
docker compose up -d

# 2. Приложение
mvn spring-boot:run
```

Откройте http://localhost:8080

Администратор создаётся при первом запуске: **admin / admin12345** (смените пароль в «Настройки → Безопасность»).

### Без Docker

```bash
psql -U postgres -f db/init.sql     # создаёт пользователя и базу vybe/vybe
mvn spring-boot:run
```

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DB_URL` | `jdbc:postgresql://localhost:5432/vybe` | JDBC URL |
| `DB_USER` / `DB_PASSWORD` | `vybe` / `vybe` | Доступ к БД |
| `VYBE_STORAGE` | `./vybe-data` | Папка для видео, обложек, аватаров |
| `FFMPEG_PATH` / `FFPROBE_PATH` | `ffmpeg` / `ffprobe` | Пути к ffmpeg |
| `VYBE_ADMIN_USER` / `VYBE_ADMIN_PASSWORD` | `admin` / `admin12345` | Первый администратор |
| `PORT` | `8080` | HTTP-порт |

Сборка jar: `mvn clean package` → `java -jar target/vybe-1.0.0.jar`

## Возможности

**Зрителю**: главная с hero-трендом, «Продолжить просмотр», «Новое в подписках», Smart Feed с бесконечной прокруткой и skeleton-загрузкой; превью видео при наведении; поиск с подсказками; категории; тренды за 24 ч / неделю / месяц; история, избранное, понравившиеся, плейлисты и коллекции; подписки.

**Страница просмотра**: собственный HTML5-плеер (скорость, громкость, перемотка с подсказкой главы, двойной клик ±10 с, горячие клавиши K/J/L/F/M/T/I/0–9, Shift+N), ambient-подсветка, главы с метками на таймлайне, автовоспроизведение следующего, лайки/дизлайки, подписка, комментарии с ответами, закрепом и «сердцем» автора, жалобы, «Поделиться» с таймкодом.

**Уникальное**
1. **Smart Feed** — ранжирование по интересам из истории (категории, теги, авторы), подпискам, свежести, популярности и качеству, с диверсификацией авторов и пояснением «почему рекомендовано».
2. **Focus Mode** (`T`) — скрывает всё, кроме видео.
3. **Mini Player** (`I` или кнопка на карточке) — плавающий плеер, который продолжает играть при переходе по сайту; плюс автоматический плавающий плеер при прокрутке страницы просмотра.
4. **Watch Together** — комнаты по коду: синхронные play/pause/перемотка, смена видео, чат и живые реакции через WebSocket.
5. **Smart Search** — название, описание, теги, каналы; ранжирование по релевантности, фильтры по длительности и категории.
6. **Chapters** — строки `00:00 Название` в описании превращаются в главы.
7. **Collections** — цветные тематические доски с иконками (отдельно от плейлистов).
8. **Trending** — рейтинг по реальным просмотрам за период.
9. **Creator Studio** — панель, контент, редактирование, обложки, удаление, модерация комментариев.
10. **Watch Statistics** — графики просмотров и подписчиков за 7/30/90/365 дней, статистика по каждому видео.

**Админ-панель** (`/admin`): статистика платформы с графиком, пользователи (блокировка, роли), видео (скрытие, удаление), категории (CRUD), жалобы (отклонить / удалить контент).

## Архитектура

```
com.vybe
├── config      Security, WebSocket, раздача медиа (HTTP Range), начальные данные
├── entity      JPA-сущности (User, Video, Comment, Playlist, ViewEvent, Report …)
├── repository  Spring Data JPA, только параметризованные JPQL-запросы
├── service     Бизнес-логика: видео, рекомендации, поиск, статистика, хранилище, ffmpeg
├── web         Thymeleaf-контроллеры страниц
├── api         REST API (JSON DTO, без сериализации сущностей)
├── ws          Watch Together (WebSocket)
├── dto         Формы с валидацией и API-ответы
└── exception   Исключения и обработчики (HTML-страницы ошибок / JSON для API)
```

Безопасность: BCrypt (cost 12), CSRF для форм и fetch/XHR, роли USER/ADMIN, remember-me, валидация форм, файлы сохраняются под UUID-именами с проверкой расширения и типа, защита от path traversal.

Генерация обложек: своя обложка → кадр через ffmpeg → кадр, выбранный в браузере при загрузке → фирменная сгенерированная обложка (Java2D). Длительность — ffprobe или метаданные из браузера.
